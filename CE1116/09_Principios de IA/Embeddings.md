## 📚 Idea/Concepto 
Un Embedding es un vector que mapea el significado de un token de forma espacial. Poniendo cerca otros Embedding que tienen significados similares. El vector inicial de un embedding se genera en el proceso de entrenamiento, dando valores a lo que se conoce como matriz de encajamiento. A partir de esa matriz se extraen los embeddings de cada token. Luego el valor de este vector se refina en el proceso de análisis de los transformers. Donde a medida que se calcula la relación de un token con otro se actualiza el embedding para el contexto actual.
