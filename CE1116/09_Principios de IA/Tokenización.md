## 📚 Idea/Concepto 
Tokenización es el proceso por el cual una palabra en un lenguaje humano se le asigna un valor numérico (id) el cual el modelo puede procesar y entender. El significado de la palabra luego se procesa mapeando el id al embedding asociado en la matriz de encajamiento. De esta forma un modelo también puede producir una cadena de tokens que se pueden traducir a un lenguaje humano. Un token no es necesariamente una palabra completa, sino que también pueden ser partes de una palabra o letras que complementan el significado de otra palabra. Existen tipos de tokenización con algoritmos variados que ayudan a procesar palabras grandes o raras de manera eficiente.
