## 📚 Idea/Concepto 
La arquitectura de microkernel, también conocida como arquitectura Plug-In, es un paradigma diseñado para la extensibilidad y adaptabilidad. Es una arquitectura monolítica relativamente simple que consta de dos componentes: un sistema central y componentes plug-in. El sistema central se define como la funcionalidad mínima necesaria para ejecutar el sistema. Su objetivo es eliminar la complejidad ciclómática y ubicarla en complementos independientes para una mejor extensibilidad, facilidad de mantenimiento y capacidad de prueba. Los componentes (plug-in), son programas independientes que contienen procesamiento especializado. El mecanismo central necesita un registro de componentes para saber qué módulos de complemento están disponibles y cómo acceder a ellos.
