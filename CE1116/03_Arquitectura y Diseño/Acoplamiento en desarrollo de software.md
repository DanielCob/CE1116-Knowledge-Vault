## 📚 Idea/Concepto 
Es una medida de la interdependencia entre los elementos de un programa. El acoplamiento entre clases o subsistemas es una medida de cuán interconectados están. El acoplamiento fuerte significa que las clases relacionadas tienen que conocer detalles internos unas de otras, lo que hace que los cambios se propaguen a través del sistema y lo vuelve más difícil de entender. Normalmente se busca tener un bajo acoplamiento. Lograr un acoplamiento débil es clave para que el código sea más fácil de leer, para aislar posibles cambios a un área pequeña de código y para reutilizar clases en contextos completamente nuevos.
