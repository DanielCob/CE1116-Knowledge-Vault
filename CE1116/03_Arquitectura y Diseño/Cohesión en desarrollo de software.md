## 📚 Idea/Concepto 
Es una medida de la fuerza de asociación de los elementos dentro de un módulo. Mide cuán estrechamente relacionadas están todas las responsabilidades, datos y métodos de una clase entre sí. Escribir código procurando una alta cohesión permite facilitar la lectura y comprensión del sistema. Así como facilitar la futura modificación del código ya que las secciones que deben cambiar se encuentran cercanas unas entre otras.
